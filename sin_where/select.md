# Evidencia CRUD - READ / SELECT

## Objetivo
Validar la consulta y recuperación de información.

## Riesgos asociados
- Consultas sin filtros.
- Exceso de registros devueltos.
- Bajo rendimiento.
- Consulta de información no requerida.

## Caso de prueba
Consultar pagos según un criterio definido.

## Resultado esperado
Solo deben aparecer los registros que cumplan con el filtro establecido.

## Evidencia
- Consulta SELECT.
- Resultado filtrado.
- Captura del resultado.
